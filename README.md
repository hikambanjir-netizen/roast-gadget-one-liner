A tiny Node 22 program (standard library only) that writes one original roast line about a gadget used every day to `/output/entry.txt`. One line, 113 characters, no network, no model calls, the same bytes every run.

> My printer is the only gadget that asks for a subscription to print the email telling me my subscription expired.

## Run it

```sh
node main.ts
```

## Why this angle

Not the phone battery, not the kettle firmware update — the printer's subscription loop: it charges you for the privilege of reading the email that says you owe it money. One concrete detail, one ironic loop, and the last word pays the joke off.
